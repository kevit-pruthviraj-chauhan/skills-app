# skills-app

Python backend generated by Better Fullstack.

## Development

Install dependencies:

```sh
uv sync --extra dev
```

Run the application:

```sh
uv run uvicorn app.main:app --reload --host 0.0.0.0 --port ${PORT:-8000}
```

Production with Gunicorn:

```sh
uv run gunicorn app.main:app --worker-class uvicorn.workers.UvicornWorker
```

The health endpoint is available at `/health`.
